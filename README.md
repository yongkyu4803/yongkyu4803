# 코딩하는 보좌관입니다 👋

**입법데이터를 더 쉽게 찾고 활용하는 AI 도구를 만듭니다.**

법안과 정부 발표 자료를 검색 가능한 도구로 연결하고, 업무효율화를 시도합니다.
- 매일 발의되는 국회법안을 가장 먼저 정리해 배포합니다.
- 정부 보도자료를 한눈에 볼 수 있도록 스킬 및 mcp로 사용할 수 있습니다.
- AI 시대에 한발 앞서가기 위한 바이브코딩 사이트를 운영합니다.
